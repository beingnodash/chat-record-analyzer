# Concepts

## 背景

企业微信外部群中的聊天记录可通过会话存档能力同步到后台。AI agent 不直接对接企业微信接口，而是分析不断 append 的聊天文本，判断是否需要生成 bot 话术或表单卡片 URL。

## 第一阶段核心概念

- AI 侧是一个介入决策器，不是完整企业微信机器人。
- POC 优先证明触发质量：何时介入、何时不介入、为什么。
- 输入是带元数据的 canonical JSONL 文本。
- 输出是可解释的结构化决策。
- 表单来自配置 catalog，模型不自由生成真实表单。

## 成功信号

- 正确识别商机信息缺口。
- 能引用触发判断的 `chatseq` 证据。
- 能稳定输出置信度和 rubric 分数。
- 不确定时默认不介入，避免打扰外部群成员。
