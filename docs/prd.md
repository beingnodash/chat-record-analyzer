# PRD

## 目标

构建一个可部署到 Streamlit Cloud 的 POC，验证 AI 能否从企业微信风格聊天存档中判断是否应该介入，并生成可解释的介入建议。

## 用户

主要用户是业务/产品方，需要通过样本复盘理解 agent 的判断依据和稳定性。

## 功能需求

- 上传或选择聊天 JSONL 样本。
- 选择分析到某个 `chatseq` 为止的会话状态。
- 输出结构化决策：是否发送、动作类型、置信度、证据、理由、话术、表单。
- 展示 rubric 评分，帮助业务方判断稳定性。
- 支持多主题样本，用于扩展性验证。

## 非目标

- 不对接企业微信 API。
- 不构建真实表单系统。
- 不处理会话存档同步频率。
- 不在第一版引入 LangChain/LangGraph。

## 验收标准

- 泰国港口照明样本在 `chatseq=4` 建议信息收集话术。
- 泰国港口照明样本在 `chatseq=6` 建议发送照明方案收集表单。
- bot、内部员工或普通寒暄后的最新消息不触发发送。
- 所有决策都能给出可复盘的证据和评分。
